# Лабораторная работа 10: Разработка защищенных скриптов автоматизации и сборщик артефактов (Incident Response)

## 🎯 Цели работы
1. Провести аудит и устранить уязвимости внедрения команд (Command Injection) в скриптах Bash.
2. Реализовать безопасный механизм работы со временными файлами, исключающий race condition (TOCTOU).
3. Разработать production-grade сборщик энергозависимых данных (Incident Response Triage Collector) в строгом соответствии с RFC 3227.
4. Создать демон мониторинга целостности хоста (Host Integrity Monitor) для обнаружения аномальных SUID-бинарников и учетных записей.

---

## 📁 Стартовые данные
В каталоге `10-bash-automation/`:
- `starter_data/vulnerable_script.sh` — пример небезопасного скрипта с уязвимостью в `eval`.
- `production_backup.sh` — эталонный скрипт бэкапа с блокировками `flock` и перехватом `trap`.

---

## 📝 Задания

### Задание 1: Аудит и устранение Command Injection в `vulnerable_script.sh`
1. Проанализируйте `vulnerable_script.sh`. Сформируйте входные аргументы для проверки внедрения произвольной системной команды (например, вызов `id` или чтение `/etc/hosts`).
2. Перепишите скрипт, полностью исключив вызов `eval`.
3. Замените статический файл `/tmp/admin_job.tmp` на безопасный временный каталог, создаваемый через `mktemp -d`, с гарантированным удалением при любом сценарии завершения через `trap '...' EXIT INT TERM`.

---

### Задание 2: Разработка сборщика форензик-артефактов (`ir_collector.sh`)
Напишите Bash-скрипт экстренного реагирования на инциденты, выполняющий сбор информации в порядке изменчивости:
1. Создает каталог `/tmp/ir_case_YYYYMMDD_HHMMSS/`.
2. Собирает дамп активных сокетов (`ss -tulnep`) в `sockets.txt`.
3. Собирает полное дерево процессов со всеми аргументами (`ps auxfww`) в `processes.txt`.
4. Собирает список залогиненных пользователей и историю входов (`w`, `last -n 20`) в `users.txt`.
5. Собирает список интерфейсов, IP и маршрутов в `network.txt`.
6. Вычисляет контрольные суммы SHA-256 для каждого собранного текстового файла и формирует манифест `checksums.sha256`.
7. Упаковывает всё в архив `evidence.tar.gz` и устанавливает права `0600` (только root).

---

### Задание 3: Разработка Host Integrity Checker
Создайте скрипт `host_audit.sh`, который за один проход проверяет:
- Все файлы с битами SUID/SGID в корневой системе и сравнивает их количество с белым списком.
- Все учетные записи в `/etc/passwd`, имеющие UID 0 (кроме пользователя `root`).
- Доступность записи в конфигурационные файлы `/etc/sudoers` и `/etc/crontab` для пользователей группы `others`.

---

## 📌 Критерии приемки
- `vulnerable_script.sh` корректно обрабатывает спецсимволы без выполнения сторонних команд.
- Скрипт `ir_collector.sh` успешно создает подписанный хэшами архив с артефактами.
- Скрипт `host_audit.sh` находит тестовый SUID файл или подозрительного пользователя.
