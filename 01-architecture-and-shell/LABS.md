# Лабораторная работа 01: Bash-конвейеры, анализ логов и фильтрация данных

## 🎯 Цели работы
1. Освоить фильтрацию и анализ системных логов при расследовании инцидентов с помощью `grep`, `awk`, `sed`, `sort`, `uniq`.
2. Научиться выполнять трансформацию структурированных текстовых данных (CSV) без использования внешних языков программирования.
3. Отработать безопасные приемы поиска и удаления файлов со сложными именами (пробелы, спецсимволы) с помощью `find` и `xargs`.
4. Закрепить работу с файловыми дескрипторами и перенаправлениями потоков ввода/вывода (`>`, `>>`, `2>`, `&>`, `tee`).

---

## 📁 Стартовые данные
Файлы для заданий расположены в каталоге: `01-architecture-and-shell/starter_data/`
- `server_access.log` — 3000 строк реального веб-журнала Nginx.
- `employees.csv` — выгрузка базы данных сотрудников.
- `messy_filesystem/` — тестовое дерево каталогов с проблемными именами и скрытыми файлами.

*(Если файлов нет, выполните: `python3 starter_data/generate_data.py`)*

## 📝 Задания

### Задание 1: Расследование инцидента безопасности в веб-логах (`server_access.log`)
Представьте, что система мониторинга зафиксировала всплеск 4xx/5xx ошибок и подозрительные запросы.
1. **Топ атакующих IP-адресов**: Сформируйте команду конвейера, которая подсчитает количество запросов с каждого IP-адреса и выведет топ-3 самых активных IP в формате: `[Количество] [IP]`.
2. **Аудит попыток взлома**: Найдите все уникальные URL-адреса, к которым обращались сканеры (запросы, содержащие `.php`, `.env` или `.git`).
3. **Ошибки сервера**: Посчитайте суммарное количество ответов со статусом `500` (Internal Server Error) и `502` (Bad Gateway).
4. **Анализ User-Agent**: Выделите уникальные User-Agent, используемые для сканирования, отбросив стандартные браузерные строки (Mozilla, Chrome, Firefox).

---

### Задание 2: Обработка структурированных данных (`employees.csv`)
1. **Выборка специалистов**: Используя `awk`, выведите список сотрудников (Имя и Фамилию, а также Email) только из департаментов `DevOps` и `Security`, у которых зарплата превышает `300000`.
2. **Расчет зарплатного фонда**: С помощью `awk` подсчитайте среднюю зарплату сотрудников департамента `Engineering`.
3. **Генерация системных логинов**: С помощью `sed` или `awk` трансформируйте email адреса вида `i.ivanov@corp.local` в формат системных учетных записей Linux `ivanov_i` (или выделите имя пользователя до `@`).

---

### Задание 3: Продвинутая навигация и очистка в `messy_filesystem/`
1. **Поиск файлов с пробелами**: Найдите все файлы с расширением `.sql` внутри каталога `messy_filesystem/`, даже если в их пути содержатся пробелы.
2. **Поиск крупных файлов**: Найдите все файлы размером строго более `1 МБ` и выведите их размер в удобном формате (human-readable) вместе с именем.
3. **Поиск секретов**: Найдите скрытый конфигурационный файл (начинающийся с точки `.`) и извлеките значение токена/ключа, записанного внутри него.
4. **Безопасное удаление**: Сформируйте команду `find` с параметром `-print0` и `xargs -0` (или `-exec`), которая безопасно удалит все временные файлы с расширением `.tmp`, не спотыкаясь о пробелы в именах.

---

### Задание 4: Перенаправление потоков и логирование
1. Выполните команду поиска несуществующего файла в `/root` и существующего файла в `/etc` так, чтобы:
   - Стандартный вывод (`stdout`) записался в файл `found.txt`.
   - Ошибки доступа (`stderr`, Permission denied) записались в файл `denied.log`.
2. Напишите однострочник с `tee`, который выводит текущую дату и список открытых портов (или текущих процессов) на экран и одновременно дописывает эти данные в `audit.log`.

- Все команды оформлены в виде однострочников Linux CLI.
- В Задании 3 файлы с пробелами корректно обрабатываются без ошибок `No such file or directory`.
- Решения проверены и сверены с `SOLUTIONS.md`.
