# Лабораторная работа 05: Пакетный менеджмент, зависимости и сборка ПО из исходного кода

## 🎯 Цели работы
1. Освоить инспекцию установленных пакетов и определение принадлежности файлов с помощью `dpkg` / `rpm`.
2. Научиться компилировать утилиту на C из исходного кода с изолированным префиксом (`/opt/...`) и настраивать интеграцию в систему.
3. Исследовать динамические зависимости исполняемого файла с помощью `ldd` и понять работу кэша линкера `ldconfig`.
4. Научиться диагностировать и устранять сбои в конфигурациях репозиториев (APT и DNF).

---

## 📁 Стартовые данные
В каталоге `05-package-management/starter_data/` находятся:
- `sample_c_project/` — исходный код системной утилиты мониторинга `sysstat_mini` с `Makefile`.
- `broken_repo/` — поврежденные конфигурации репозиториев (`broken_apt.list`, `broken_dnf.repo`).

### Задание 2: Сборка системной утилиты `sysstat_mini` из исходного кода
Перейдите в директорию `starter_data/sample_c_project/`.
**Требования:**
1. Ознакомьтесь с кодом в `src/` и изучите `Makefile`.
2. Скомпилируйте проект с помощью `make`. Убедитесь, что объектные файлы `.o` и бинарный файл `sysstat_mini` успешно собраны без предупреждений компилятора.
3. Выполните установку утилиты в директорию `/opt/sysstat_mini` (используйте параметр `PREFIX=/opt/sysstat_mini`).
4. Запустите `/opt/sysstat_mini/bin/sysstat_mini` и убедитесь, что утилита выводит системные метрики (Uptime, RAM, Load Average).
5. Сделайте так, чтобы любой пользователь системы мог запустить `sysstat_mini` просто по имени, не вводя полный путь `/opt/...` (создайте симлинк в `/usr/local/bin/`).

### Задание 5: Исследование вектора `LD_PRELOAD` и аудит бинарников (`checksec`)
В `starter_data/preload_hook.c` подготовлен код разделяемой библиотеки для перехвата стандартных вызовов `puts()`.
1. Скомпилируйте библиотеку в динамический объект `.so`:
   ```bash
   gcc -shared -fPIC -o /tmp/hook.so starter_data/preload_hook.c -ldl
   ```
2. Запустите любую системную утилиту (например, `whoami` или ранее собранный `/opt/sysstat_mini/bin/sysstat_mini`) с активной переменной `LD_PRELOAD`:
   ```bash
   LD_PRELOAD=/tmp/hook.so /opt/sysstat_mini/bin/sysstat_mini
   ```
3. Объясните результат: почему перед выводом баннера появилась строка `[⚠️ AUDIT LD_PRELOAD]`?
4. *Вопрос по безопасности*: Почему `LD_PRELOAD` автоматически отключается ядром при запуске бинарных файлов с битом SUID? (Изучите флаг `AT_SECURE` в glibc).
5. Проверьте флаги компилятора собранного бинарника `sysstat_mini` с помощью `readelf -l` или `checksec`. Включены ли Stack Canary и NX?
